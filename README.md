# ⚡ The Sixth Sense — Real-Time Football Tactical Intelligence

> **Microsoft Premier League Hackathon 2026** submission

An AI system that detects dangerous tactical patterns **3-5 minutes before they result in goals** by analysing real-time synthetic match events and matching them against historical patterns.

## 🎯 What It Does

- **Ingests** synthetic match events (passes, shots, tackles, pressures) in real-time
- **Detects** tactical patterns: counterattacks, sieges, high press, forward surges
- **Scores** match tension 0–100 as events unfold
- **Explains** WHY moments matter — not just what happened
- **Personalises** for two audiences: Tactical Analyst mode & Casual Fan mode

## 🏗️ Architecture (5-Stage Pipeline)

```
[Synthetic Events] → [Event Buffer] → [Pattern Engine] → [Tension Score] → [AI Narrative] → [Live Dashboard]
```

| Stage | Component | Tech |
|---|---|---|
| Ingest | `engine/synthetic_generator.py` | Python, football probability models |
| Interpret | `engine/pattern_engine.py` | NumPy, 40-dim feature vectors |
| Explain | `engine/narrator.py` | Groq / Azure OpenAI GPT-4o |
| Render | `dashboard/index.html` | HTML/CSS/JS, real-time UI |
| Personalise | Analyst + Fan modes | Dual-prompt LLM strategy |

## 🚀 Run Locally

```bash
pip install -r requirements.txt
export GROQ_API_KEY=your_key_here
cd api && uvicorn server:app --reload
# Open http://localhost:8000
```

## ☁️ Azure Deployment

Designed for **Azure Container Apps**:
```bash
az containerapp up --name sixth-sense \
  --resource-group Aihackathon \
  --source . \
  --env-vars GROQ_API_KEY=secretref:groq-api-key
```
See `azure-container-apps.yml` and `Dockerfile` for full config.

Uses synthetic football-realistic data generated by `engine/synthetic_generator.py` — producing statistically accurate match events based on Premier League averages (72-78% pass accuracy, 12-18 shots per match, realistic xG distribution).
